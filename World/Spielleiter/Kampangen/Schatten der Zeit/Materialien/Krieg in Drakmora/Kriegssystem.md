Jede Runde:
1. Einkommen (+2 Truppen pro Stadt, +1 pro Region)
2. Moral prüfen (+1 angrenzen an Verbündete, -1 angrenzen an Gegner)
3. Ereignis würfeln (pro Region)
4. Diplomatie zu Neutral
5. Kämpfe
6. Bewegungen (gewichteter Mittelwert bei Moral für Truppen Mischung)


**Kampfstärke = Truppen + Moral + W20

## Truppentabelle

| **Differenz** | **Ergebnis**                                   | Moral                   |
| ------------- | ---------------------------------------------- | ----------------------- |
| 0-5           | Beide verlieren 2 Truppen                      | 0                       |
| 5-10          | Sieger verliert 2, Verlierer 4                 | +1 Sieg / -1 Niederlage |
| 10-15         | Sieger verliert 1, Verlierer 5                 | +2 Sieg / -2 Niederlage |
| 15-20         | Verliere 6                                     | +4 Sieg/-4 Niederlage   |
| >20           | Verlierer kapituliert, die Truppen laufen über | +5 Sieg                 |
## Ereignisstabelle

| **Wurf** | **Ereignis**              |
| -------- | ------------------------- |
| 1        | Seuche (-2 Truppen)       |
| 2        | Deserteure (-1 Moral)     |
| 3        | Regen (alle Angriffe -2)  |
| 4        | Nichts                    |
| 5        | Freiwillige (+2 Truppen)  |
| 6        | Held erscheint (+1 Moral) |
| 7        | Spione (-2 Verteidigung)  |
| 8        | Großer Sieg (+2 Moral)    |

## Diplomatie
Versuch pro Anführer (Fürsten 1, Rebellen 2)
Diplomatie = (ANG W6 - VER W6) + Bonus + Drohungen ((ANG Truppen - VER Truppen)/2)

**Vorteil** wenn Moral >= 2 * Gegnermoral
**Nachteil** wenn Moral <= 0.5 * Gegnermoral

**Boni:** 
- +1 pro Angrenzendes Gebiet der eigenen Fraktion
- -1 pro Angrenzendes Gebiet der Gegner Fraktion
- -2 wenn letzte Runde angegriffen
**Drohungen:**
- Truppendifferenz/2

| Differenz | **Ergebnis**  | **Effekt**                                |
| --------- | ------------- | ----------------------------------------- |
| < 0       | Niederlage    | Loyalität verschiebt sich um 1 zum Gegner |
| > 0       | Erfolg        | Loyalität +1                              |
| > 5       | Großer Erfolg | Loyalität +2                              |
